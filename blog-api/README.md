## 🎯 Быстрый Старт

```bash
# 1. Установите AI Factory
npm install -g ai-factory

# 2. Создайте тестовый проект
composer create-project laravel/laravel blog-api
cd blog-api

# 3. Инициализируйте
ai-factory init

# 4. Откройте AI-агент и начните первый урок!
```

## 💡 Советы по Обучению

1. **Не пропускайте уроки** — каждый строится на предыдущем
2. **Выполняйте задания** — теория без практики бесполезна
3. **Экспериментируйте** — создавайте тестовые проекты и пробуйте
4. **Используйте `/aif-explore`** — прежде чем планировать, исследуйте
5. **Запускайте `/aif-evolve`** регулярно — AI станет умнее
6. **Чек-листы в конце** — проверяйте что всё выполнено
